## Users and purpose

The owner operates a Windows-hosted workspace locally, including while disconnected. The primary task is selecting an editable role profile and conducting a persisted conversation with a preinstalled local model.

## Capabilities and constraints

Sixteen starter profiles are editable prompt templates, not autonomous agents or a verified organization. Enabled profiles permit selection; active runs are separate. Conversations are local SQLite records. Memory is conversation persistence, not automatic retrieval.

Ollama runs as a dedicated loopback child with cloud disabled. A runtime and suitable licensed model must be provisioned before going offline. No cloud fallback, downloads, tool execution, media generation, accounts, or deployment.

Uploaded JPEG/PNG images and short H.264 MP4 videos personalize profiles, not model input. Images use the installed image decoder dependency; videos require preinstalled FFmpeg/ffprobe. Media stays local and can be replaced/deleted.
